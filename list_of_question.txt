*1. Cache Poisoning (CAPEC-141)**
*   **Explanation of Malware Use:** In a cache poisoning attack, an attacker manipulates cache technologies to store incorrect or harmful data. This can lead to various exploits, including redirecting web browsers to sites that install malware. The malware itself is the malicious software that gets installed on the victim's system after being redirected to a compromised site.
*   **Malware Description:** Malware, in this context, refers to the malicious software that is delivered to the victim's system. It could be a virus, worm, trojan, or other type of malicious code designed to compromise the system, steal data, or perform other harmful actions.
